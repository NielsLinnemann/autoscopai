How AutoscopAI works

1. Drop your text

Drop one main article file: PDF, LaTeX, Markdown, or plain text. You may add one bibliography/reference file, such as a BibTeX file.

2. Choose a mode

Cheapest keeps costs down. Balanced uses a stronger mix. Most suitable prioritizes review quality and may cost more.

3. Add your API key

For real reviews, enter a provider API key in Settings. The key is saved only in this browser's local storage on this computer, and is sent directly from this page to the provider you choose. TEST mode is only shown in Developer mode.

4. Read the results

The final verdict appears below the workflow. History keeps previous runs, intermediate agent feedback, and common learnings for future writing.

Treat the output as fallible feedback, not as an authority. Cost estimates are rough planning aids and can differ from actual provider charges. This build runs a real Python engine inside your browser via Pyodide (WebAssembly) — there is no server and no separate Python install.

Settings

Warning: the uploaded article, references, and prompts are sent to your selected third-party model provider (OpenRouter, OpenAI, or a custom endpoint) to generate reviews, directly from this browser page. Check for yourself whether you are comfortable sending this material to the provider configured above before uploading confidential or unpublished work.
